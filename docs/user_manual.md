# User Manual (Quick)

## Start

1. Build:

```bash
./scripts/create_build.sh
```

2. Run:

```bash
./build-gui/library_gui
```

## Login

- **Librarian**: `admin / admin123`
- **Student**: `100001 / 0001`, `100002 / 0002`

## What each role can do

- **Librarian**
  - Manage books (add/edit/delete)
  - Manage students (register/delete)
  - Issue books + return books
  - Save / Reload data
- **Student**
  - Search/view books
  - Request books (queue)
  - Return books (for their own student ID)
  - Use Student Assistant (recommendations/help)
